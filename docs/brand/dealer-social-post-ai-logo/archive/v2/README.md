# Retired v2 identity archive — do not use

Status: **retired / historical reference only**

This directory preserves the superseded **Key Moment Post** people-and-car
identity, its exploration images, masters, exports, specifications, and visual
proofs. It is retained so the decision history remains auditable.

Nothing in this directory is an approved alternate, fallback, co-brand, app
icon, or production asset. The active v3 identity lives at the package root.

Retirement reason: the illustrated salesperson/customer/vehicle/key/post scene
carried too many literal details for a durable small-scale product identity.
The v3 campaign-aperture `DSP` monogram replaces it.

The generic arrow direction rejected during the v3 review was never a selected
v2 master and is documented in the active `rationale.md`.
