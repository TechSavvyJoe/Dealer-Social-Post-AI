# Dealer Social Post AI identity package

Status: **production-candidate** pending naming clearance, client approval, and a
verified outlined wordmark export.

The selected system replaces the aperture/road artwork with **Key Moment Post**:
a salesperson and customer share a vehicle-delivery moment inside a social-post
card, with a cyan key and one restrained AI polish point. It expresses the
actual product workflow while retaining a dedicated micro version for favicons.

## Included

- Editable, literal wordmark source using the bundled Inter typeface.
- Horizontal, stacked, symbol, micro, black, and reverse SVG variants.
- Browser, Apple, PWA, and maskable exports.
- Light/dark, small-size, header, avatar, and safe-zone proofs.
- Brief, rationale, color/type, spacing, minimum-size, license, misuse, and
  validation records.

## Approval boundary

The symbol paths are deterministic vector artwork. The wordmark remains live
text in the editable source so spelling can be audited. Before declaring the
package production-ready, approve the name, complete professional trademark
clearance, convert the approved wordmark to outlines in a trustworthy vector
editor, and render-compare those outlines against the editable source.
